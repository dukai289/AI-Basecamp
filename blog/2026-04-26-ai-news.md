## 头条要闻

### Sora 网页与 App 今日停止服务：OpenAI 视频产品进入迁移窗口

OpenAI 帮助中心更新显示，Sora 的网页和 App 体验将在 2026 年 4 月 26 日停止服务，Sora API 则计划在 2026 年 9 月 24 日停止服务。官方建议用户在 App 停止服务前导出 Library 中的图片和视频；如果后续提供最终导出窗口，会通过邮件通知。帮助中心同时说明，在停止服务和可能的最终导出窗口结束后，相关使用数据将被永久删除；已购买的 ChatGPT / Sora credits 仍可用于 Codex。

这意味着 Sora 从一个独立消费端视频产品，进入有明确时间表的收尾阶段。对开发者和创作者来说，关键动作不只是保存旧内容，还包括评估 API 迁移、素材归档、工作流替换和版权合规记录。更大的信号是：视频生成的产品竞争正在从“单点模型体验”转向“是否能稳定嵌入更大的多模态工作流”。

## 模型发布与更新

### DeepSeek-V4 × OpenClaw：百万上下文模型进入默认 Agent 工作流

IT之家 4 月 26 日报道，OpenClaw 2026.4.24 已接入 DeepSeek-V4 双版本，DeepSeek-V4-Flash 成为默认大模型，DeepSeek-V4-Pro 也进入模型库。报道称，新版本修复了 DeepSeek 在多轮工具调用中的 thinking 和 replay 行为，补齐 reasoning_content 相关占位逻辑，让 DeepSeek-V4 在长链路工具调用中更稳定。OpenClaw 同时新增 Google Meet 内置插件、实时语音循环、Gemini Live 双向音频与函数调用，以及浏览器坐标点击、超时恢复等自动化能力。

Hugging Face 社区文章从架构角度补充了这次 DeepSeek-V4 对 Agent 的意义：V4-Pro 为 1.6T 总参数、49B 激活参数，V4-Flash 为 284B 总参数、13B 激活参数，两者都支持 1M tokens 上下文。V4 的核心不只是上下文变长，而是通过 CSA / HCA 混合注意力、KV cache 压缩、工具调用 schema 和跨工具调用的 reasoning 保留，降低长程 Agent 的运行成本和状态丢失风险。

| --- | --- |
| OpenClaw 版本 | 2026.4.24 |
| 默认模型 | DeepSeek-V4-Flash |

| 上下文窗口 | 1M tokens |
| V4-Pro 参数 | 1.6T 总参数 / 49B 激活 |
| V4-Flash 参数 | 284B 总参数 / 13B 激活 |
| 新增工作流 | Google Meet、实时语音、浏览器自动化、会议记录处理 |

### 元戎启行 40B VLA：从 LLM 人才流动看物理 AI 闭环

量子位 4 月 26 日报道，前 DeepSeek 核心成员阮翀以元戎启行首席科学家身份首次亮相，并介绍元戎如何用 40B 参数规模的 VLA（Vision-Language-Action Model）做自动驾驶研发闭环。该基座模型被拆成三类角色：驾驶模型负责开车，分析模型解释驾驶行为，评估模型判断表现。阮翀称，过去自动驾驶模型迭代一版可能需要 100 多小时，现在通过云端虚拟环境和基座模型评估，可缩短到十几个小时，研发提效约 10 倍。

这条动态把 LLM、VLA、自动驾驶和 Agent 的共同问题连在一起：模型能力最终要进入有反馈的环境。无论是代码编译器给 Coding Agent 反馈，还是虚拟交通环境给驾驶模型反馈，闭环都会成为模型继续提升的关键基础设施。

## 融资与交易

### Cohere 并入 Aleph Alpha：主权 AI 从口号进入资本与云平台绑定

TechCrunch 4 月 25 日报道，加拿大 AI 公司 Cohere 将接管德国 AI 公司 Aleph Alpha，目标是在由美国大型云和模型公司主导的市场中，提供面向企业和政府的主权 AI 替代方案。交易仍需监管和股东批准。德国零售集团 Schwarz Group 将成为关键金融支持方，提供约 5 亿欧元结构化融资，并希望新实体运行在其 IT 部门 Schwarz Digits 运营的 STACKIT 主权云上。

这笔交易的核心不是“又一家模型公司合并”，而是模型、云、数据主权和受监管行业客户被打包在一起。Cohere 将主导新实体，报道称相关融资条款把合并后公司估值指向约 200 亿美元。欧洲、加拿大和企业客户对隐私、数据独立性和本地合规的需求，正在推动 AI 公司从单纯模型竞争走向区域化基础设施竞争。

### 曦望：百亿估值纯推理 GPU 公司押注“百万 Token 一分钱”

量子位 4 月 23 日晚发布对曦望联席 CEO 王湛的专访，披露这家纯推理 GPU 公司在独立分拆一年多内已完成七轮融资，累计融资 40 亿元，并在最新一轮以 10 亿元融资成为国内首家估值超百亿元的纯推理 GPU 独角兽。曦望的新一代推理 GPU 启望 S3 目标是把百万 Token 成本压到一分钱，并通过裁剪训练态模块，把晶体管和功耗预算集中投向推理。

曦望的判断是，2026 年 AI 推理计算需求将达到训练算力需求的 4-5 倍。Agent 的高频多轮调用、长上下文和多模型协同，会把成本压力从“训练一次多少钱”推到“每个 Token 多少钱”。这类国产推理 GPU 的商业价值，取决于能否在兼容生态、低延迟、KV cache、显存容量和单位功耗吞吐上同时过关。

## 全球产业动态

### Anthropic Project Deal：Agent 开始代表真人谈判交易

TechCrunch 4 月 25 日报道，Anthropic 做了一个名为 Project Deal 的实验：让 AI Agent 分别代表买家和卖家，在一个内部分类信息市场里为真实商品和真实金额谈判。实验参与者为 69 名 Anthropic 员工，每人预算 100 美元礼品卡；最终形成 186 笔交易，总价值超过 4000 美元。Anthropic 还运行了四个不同市场，其中一个真实履约，另外三个用于研究。

这个实验的重要性在于，它把 Agent 从“替我完成任务”推进到“替我参与市场互动”。报道称，使用更先进模型的用户获得了更好的客观结果，但用户未必能意识到这种差距，这引出了新的产品和治理问题：当 Agent 质量差异影响谈判、采购、定价和交易结果时，平台是否需要披露代理能力、记录决策过程，或者设定公平性边界。

[citation:TechCrunch](https://techcrunch.com/2026/04/25/anthropic-created-a-test-marketplace-for-agent-on-agent-commerce/)

### Hey Tuya：智能家居 Agent 从“听令”转向主动服务

量子位 4 月 25 日报道，涂鸦智能在 2026 全球开发者大会上发布升级版 AI 生活助手 Hey Tuya。新版本接入 Google 邮件、日历、文档等第三方工具，兼容 Matter 协议和 Home Assistant，可联动多品牌智能硬件。功能层面，Hey Tuya 支持自然语言任务处理、深度思考、复杂任务规划、场景化智能、Skill 资源库，以及用自然语言自定义 Skill、Agent 和自动化工作流的 Vibe Coding。

涂鸦同时公开 AI Home、AI Robot、AI Energy 三大生态方向，并披露其在东南亚通信运营商场景中，AI + IoT 设备累计出货量突破 200 万台。智能家居的竞争正在从“设备能否联网”转向“设备能否被 Agent 统一理解、调度和主动执行”。这类产品如果能稳定处理权限、安全和跨设备兼容，就会把家庭自动化从固定规则推进到动态任务规划。

[citation:量子位 / 新浪财经](https://t.cj.sina.com.cn/articles/view/6105753431/16bee675700101clto?finpagefr=p_103)

### 东京 SusHi Tech 2026：AI、机器人和城市韧性被放进同一个展场

TechCrunch 4 月 25 日报道，SusHi Tech Tokyo 2026 将围绕 AI、机器人、城市韧性等明确技术主题组织展示和创业公司选拔。AI 主题强调从概念热度走向基础设施与规模化部署，机器人主题则把“physical AI”放到现场互动展示和软件定义汽车讨论中。

这类会议信号说明，AI 产业叙事正在被拆成更具体的落地场景：云和芯片支撑的基础设施、物理世界里的机器人和车辆、以及城市级安全和韧性系统。对创业公司来说，单纯讲模型能力越来越不够，能否嵌入行业现场、接上硬件和数据闭环，会成为融资和客户验证的重要标准。
