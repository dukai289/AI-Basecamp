# 2026-05-11 AI 周报

*覆盖周期：2026-05-11 至 2026-05-17。*

:::info **本周判断**
1. Daybreak、Claude for Legal、Anthropic 金融与公益合作显示行业 Agent 加速落地。  
2. 百度 DAA、Codex Mobile、Qoder 1.0 和 Grok Build 把 Agent 推向多端调度和开发者工作台。  
3. AI 视频、药物设计、材料科学和医疗健康成为垂直产业化重点。  
4. OpenClaw 百万美元级 API 账单让长程 Agent 成本进入产品讨论。

## 本周主线

### 行业 Agent 模板化

OpenAI 推出 Daybreak，把 Codex 与 GPT-5.5-Cyber 引入网络防御；Claude for Legal 扩展 20+ MCP 连接器和 12 个法律插件；OpenAI 与 PwC 将财务部门改造成 AI-native agent 工作流；Anthropic 与 Gates Foundation 合作把 Claude 部署到公益与公共部门场景。行业 Agent 正从“可定制”走向“有模板、有连接器、有访问边界”的产品形态。

### Agent 入口从 PC 扩展到移动和 IDE

百度 Create2026 提出日活智能体数 DAA，DuMate 移动端亮相；Codex 登陆 ChatGPT 手机端；阿里发布 Qoder 1.0；xAI 推出 Grok Build Beta；AGenUI 把 Agent 输出转为原生可交互界面。Agent 的入口正在从聊天框扩展到手机、IDE、CLI 和原生 UI。

### 垂直产业继续资本化

可灵 AI 被曝拟从快手分拆融资，Isomorphic Labs 完成 21 亿美元 B 轮，Microsoft 发布 MatterSim-MT，千问接入国家药监局信息中心数据。AI 视频、药物设计、材料科学和医疗健康都在从模型能力变成可估值、可集成的产业资产。

### 长程 Agent 成本显性化

OpenClaw / CodexBar 过去 30 天 API 费用被曝超过 130 万美元，约 6030 亿 token。长期运行 Agent 的成本不再只是工程后台问题，而会影响产品定价、模型选择、上下文管理和缓存策略。
