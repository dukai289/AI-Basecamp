## 本周主线

### 多模态进入世界模型和医疗视频

LingBot-World-Fast 开源并进入移动端体验，联影智能开源 uAI Nexus MedVLM 和 MedVidBench，腾讯混元 Hy3 preview 首秀 3D 世界生成，DeepSeek Vision 灰测也显示多模态能力从技术报告走向用户侧。多模态竞争开始围绕可交互世界、医疗视频和视觉推理展开。

### Agent 商业化接入云、支付和办公文件

阿里发布 QoderWake，把 Agent 推向生产级数字员工；Stripe 发布 288 项更新，Agentic Commerce 进入支付与钱包层；AWS Bedrock 接入 OpenAI 模型、Codex 和 Managed Agents；Gemini 支持直接生成 PDF、Word、Excel、Docs 等文件。Agent 正在从回答问题转向交付产物和参与交易。

### 安全访问和政府采购路径变得重要

OpenAI 获 FedRAMP Moderate 授权，GPT-5.5 与 Codex Cloud 进入美国联邦采购路径；OpenAI 推出 Advanced Account Security；Claude Security 公测。模型进入企业、政府和代码场景后，账户、访问层和安全专用模型会成为默认要求。

### 基础设施延伸到能源和国产化

Meta 签下太阳能与长期储能协议，OpenAI 称 Stargate 已提前超过美国 10GW 算力目标，中国信通院启动 DeepSeek V4 国产化适配测试。AI 基础设施竞争正在从卡和云扩展到能源、电力和本地生态适配。
