# 2026-04-20 AI 周报

*覆盖周期：2026-04-20 至 2026-04-26。*

:::info **本周判断**
1. DeepSeek-V4、GPT-5.5、Kimi K2.6 把长上下文和 Coding Agent 推到新阶段。  
2. Google Cloud Next 把企业 Agent、数据云、安全和 TPU 打成完整产品栈。  
3. Anthropic × Amazon 5GW 合作说明模型竞争进一步绑定到长期算力采购。  
4. Sora 迁移、Cohere 并入 Aleph Alpha 和 Project Deal 显示产品与资本结构继续调整。  
:::

## 本周主线

### 前沿模型进入长上下文和工作流竞争

DeepSeek-V4 预览版上线，1M 上下文成为官方服务标配；OpenAI 发布 GPT-5.5，把重点放在 Agentic Coding、电脑使用和知识工作；Kimi K2.6 开源，强调长程编码与 Agent 集群。模型竞争从 benchmark 表格进一步进入工程工作流。

### 企业 Agent 平台化

Google Cloud Next 2026 推出企业 Agent 平台、Agentic Data Cloud、安全 Agent 和 TPU 8；GitHub Copilot 打通 PR、Issue、Project 和云端 Agent 会话；飞书项目开放平台升级，JiuwenClaw Team Skills 把多 Agent 协作沉淀成能力包。企业 Agent 正在变成平台能力，而不是单点助手。

### 算力与资本绑定加深

Anthropic 与 Amazon 把 Claude 的算力合作扩大到 5GW，并绑定长期资本与 AWS 分发；OpenAI 与 Cerebras 被曝扩大至超 200 亿美元算力合作。模型公司、云厂商和芯片公司继续形成更深的采购与分发关系。

### 产品和主权 AI 进入调整期

OpenAI 的 Sora 网页与 App 体验停止服务，API 保留到 9 月 24 日；Cohere 并入 Aleph Alpha，主权 AI 从口号进入资本与云平台绑定；Anthropic Project Deal 测试 Agent 代表真人完成交易，说明 Agent 已开始触碰交易授权边界。
