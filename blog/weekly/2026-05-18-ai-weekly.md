## 本周主线

### Google I/O：Gemini 成为跨入口 Agent 层

Google I/O 2026 发布 Gemini Omni、Gemini 3.5 Flash、Antigravity、Search Information agents、Gemini Spark、Daily Brief 和 Universal Cart。Google 的 Agent 战略不是单点产品，而是把 Gemini 放进搜索、购物、Android、Workspace、开发工具和消费入口。

### 国产模型继续围绕长程 Agent 加速

Qwen3.7-Max 正式发布，强调 35 小时复杂 Agent 任务、超过 1000 次工具调用和关键内核自我优化；Qwen3.7-Max-Preview 与 Qwen3.7-Plus-Preview 此前也登上 Arena 相关报道。国产旗舰模型正在把“长程任务 + 工具调用 + 自我优化”作为核心叙事。

### Agentic AI 改写基础设施需求

NVIDIA Vera CPU 首批交付 Anthropic、OpenAI、Oracle Cloud Infrastructure 和 SpaceXAI；Google 披露月处理超过 3200 万亿 Token；JiuwenSwarm 开源并强调 Coordination Engineering。长程 Agent 不只消耗模型推理，也需要 CPU、内存、调度、协同和 Token 成本管理。

### 治理和工具链边界继续显性化

Anthropic 正式收购 Stainless，把 SDK、CLI、MCP server tooling 纳入 Claude 平台；OverEager-Bench 评测 Coding Agent 越界操作；arXiv AI 投稿治理继续发酵；Musk v. OpenAI 诉讼因时效被驳回但治理争议仍未消失。Agent 越像执行者，权限、审计和责任边界越重要。
