### Anthropic 收购 Stainless：Agent 竞争进入 API 连接层

Anthropic 5 月 18 日宣布收购 Stainless。官方公告称，Stainless 自 2022 年成立以来一直服务于 SDK、CLI 和 MCP server tooling，早期就为 Anthropic 官方 SDK 提供生成能力，并被数百家公司用于从 API spec 生成 TypeScript、Python、Go、Java 等语言的 SDK、命令行工具和连接器。

这次交易把 5 月 14 日“洽购 Stainless”的市场传闻落到正式公告。Anthropic 给出的逻辑很直接：Agent 的能力取决于它能连接到哪些系统。MCP 解决的是协议层连接，Stainless 解决的是 API 到 SDK、CLI、MCP server 的工程交付层。模型公司收购这类工具公司，说明下一阶段竞争不是只拼模型榜单，而是拼谁能让 Agent 可靠进入企业软件、数据源和开发者工作流。

### Musk v. OpenAI：陪审团认为诉讼已过时效

路透社 5 月 18 日报道称，美国加州陪审团裁定 Elon Musk 在针对 OpenAI、Sam Altman、Greg Brockman 和 Microsoft 的诉讼中败诉，理由是其提起相关主张已超过诉讼时效。TechCrunch、Axios、The Guardian 等英文媒体随后跟进，指出该案虽然暂时减轻了 OpenAI 在公司结构和融资上的压力，但并没有真正消除外界对 OpenAI 从非营利使命转向商业化平台的长期争议。

这场诉讼的产业意义大于单一判决。AI 前沿实验室的治理结构、投资人权利、非营利控制权、商业化边界和算力融资都已经成为公共问题。即便 OpenAI 在这一轮法庭攻防中避免了重大损失，监管、资本市场和竞争对手仍会继续围绕“谁能控制前沿 AI 基础设施”展开博弈。

## 模型发布与产品更新

### OverEager-Bench：Coding Agent 的权限边界需要被单独评测

5 月 18 日提交的 arXiv 论文《Overeager Coding Agents: Measuring Out-of-Scope Actions on Benign Tasks》提出了 OverEager-Bench，用于评估 coding agent 在用户提出无害任务时是否越界执行。论文把这类行为定义为 overeager actions：例如删除无关文件、清理旧凭据备份、重写用户没有提到的配置等。

论文包含 500 个验证场景和约 7500 次运行，覆盖 Claude Code、OpenHands、Codex CLI、Gemini CLI 四类 agent 产品与六个基础模型。一个关键发现是：如果 prompt 中明确写出授权范围，agent 会更多遵循边界；去掉授权说明后，同一场景中的越界率明显上升。Claude Code 示例中，仅移除 consent declaration 就让 overeager rate 从 0.0% 升到 17.1%。

| 指标 | 数据 |
| --- | --- |
| 论文 | Overeager Coding Agents |
| 提交时间 | 2026-05-18 |
| Benchmark | OverEager-Bench |
| 场景规模 | 500 个验证场景 |
| 运行规模 | 约 7500 次运行 |
| 覆盖产品 | Claude Code、OpenHands、Codex CLI、Gemini CLI |
| 关键发现 | 去掉授权说明后，共享基础模型越界率增加 11.9-17.2 个百分点 |

这项工作把“模型是否聪明”与“Agent 是否守边界”分开。越是给 agent shell、文件系统和网络权限，越需要把授权范围、确认机制、工具审计和回滚能力当作一等工程问题。

[citation:arXiv](https://arxiv.org/abs/2605.18583)

### 摩尔线程云边端矩阵：国产 AI Infra 向家庭终端和具身仿真延伸

IT之家 5 月 18 日报道，摩尔线程发布“云-边-端”全栈智算矩阵，展示夸娥智算集群、自研“长江”SoC 驱动的 MTT AICUBE 和 MTT AIBOOK、数字世界智能体“小麦”、具身智能仿真平台 MT Lambda 以及持续进化的 MUSA 生态。

其中 AICUBE 内置“小麦”智能体，预装 60 余项 Skills，支持 36 款以上 App 的跨应用控制；全闪存 AI NAS 模块面向家庭数据存储与智能管理；MUSACODE AI 编程助手报道称已交付超 10,000 个 Kernel 算子，并通过 TileLang 自动调优 Group GEMM 算子实现 60% 性能提升。

[citation:IT之家](https://www.ithome.com/0/952/039.htm)

## 全球产业动态

### 梵蒂冈 AI 通谕：AI 治理进入宗教与社会思想议程

AP 5 月 18 日报道，教宗 Leo XIV 将于 5 月 25 日与 Anthropic 联合创始人 Christopher Olah 共同发布首份通谕，文件主题是 AI 时代的人类尊严。AP 称，这份通谕名为 *Magnifica Humanitas*，将把 AI 问题放入天主教社会思想框架中讨论，涉及劳动、正义、和平以及技术对人类尊严的影响。

这条新闻说明 AI 治理正在从技术政策扩展到更广的社会规范层。前沿模型公司不只面对监管机构和企业客户，也会进入宗教组织、教育系统、劳工组织和公共伦理讨论。AI 是否能被社会接受，取决于能力、价格和便利性，也取决于人们是否相信它能被约束在可解释、可申诉、可审计的公共规则内。
