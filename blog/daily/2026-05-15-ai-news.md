### Recursive Superintelligence：自我改进 AI 成为新一轮前沿实验室叙事

5 月 13 日，Recursive Superintelligence 从隐身状态公开亮相。GV 官方文章称，公司由 Richard Socher 领导，早期融资规模为 6.5 亿美元，估值 46.5 亿美元，GV 与 Greycroft 共同领投。TechCrunch 5 月 14 日跟进报道称，团队还包括 Peter Norvig、Cresta 联合创始人 Tim Shi 等 AI 研究者，目标是构建能够识别自身弱点并重写自身代码的“递归自我改进”模型。

这条新闻的意义在于，前沿 AI 创业正在从“更大预训练模型”扩展到“让 AI 自动改进 AI”。如果系统能自动设计 benchmark、发现缺陷、生成实验并改进代码，AI 研发本身会被压缩成一个更快的闭环。但这一路线也天然伴随安全与可验证性问题：自我改进不能只追求能力提升，还必须能约束目标漂移、回滚失败实验并保留审计轨迹。

### Anthropic 融资条款被曝敲定：前沿模型公司估值继续上移

Investing.com 5 月 14 日援引 Financial Times 报道称，Anthropic 已同意一轮 300 亿美元融资条款，估值约 9000 亿美元。报道称，该轮融资预计最快本月完成，由 Dragoneer、Greenoaks、Sequoia Capital 和 Altimeter Capital 共同领投，每家共同领投方预计至少出资 20 亿美元；Anthropic 年化收入预计很快超过 450 亿美元，较去年底的约 90 亿美元增长约 5 倍。

目前这仍是媒体报道口径，并非 Anthropic 官方公告，因此更适合作为资本市场信号跟踪。它说明头部模型公司已经被投资人按“基础设施平台 + 企业软件 + 云算力入口”重新定价。与此同时，融资规模越大，也越会放大后续收入增长、算力支出、企业落地和 IPO 时间表的压力。

## 模型发布与产品更新

### Codex Mobile：代码 Agent 从桌面 IDE 走向移动调度

OpenAI 5 月 14 日发布 “Work with Codex from anywhere”，宣布 Codex 在 ChatGPT 移动 App 中以 preview 形式向 iOS 与 Android 推出，覆盖所有计划，包括 Free 与 Go，并在所有支持地区上线。用户可以在手机上查看线程、审阅输出、批准命令、切换模型或启动新任务；Codex 仍在笔记本、Mac mini、devbox 或远程环境中运行。

这次更新的关键不是“在手机上写代码”，而是把长时间运行的 coding agent 变成可随时介入的工作流。开发者可以在通勤、会议间隙或离开电脑时处理决策点、批准下一步操作、检查 diff 和继续任务。OpenAI 同时提到，手机与本地 Codex App 之间通过安全中继网络连接，Windows 版 Codex App 的手机连接支持仍在路上。

### AGenUI：Agent 输出从文本回答走向原生可交互界面

高德与阿里千问 C 端应用团队面向 AI Agent 开发者开源 AGenUI。量子位 5 月 13 日报道，AGenUI 是覆盖 iOS、Android、HarmonyOS 三端的端云一体原生 A2UI 开源框架，开发者接入 SDK 后，可以把 Agent 输出直接渲染为可交互原生卡片，而不必分别为不同平台写 UI。

AGenUI 基于 Google A2UI 协议构建：云侧通过 Agent Skill 生成 A2UI JSON，端侧用跨平台 C++ Core 负责协议解析、状态管理和布局计算，并支持流式渲染、差分更新、22 个基础组件和 45 项 CSS 属性。它解决的是 Agent 产品的一个真实瓶颈：当 AI 可以动态生成任务流程时，传统固定页面很难承接这些不确定交互。

| 项目 | AGenUI |
| 发布方 | 高德、阿里千问 C 端应用团队 |
| 支持平台 | iOS、Android、HarmonyOS |
| 架构 | 云侧 Agent Skill + 端侧 C++ Core |

### General Compute：面向 Agent 工作负载的 ASIC-first 推理云开放可用

General Compute 此前宣布，其面向 AI Agent 的推理云平台将于 5 月 15 日开放可用。公司称，该平台运行在专用 AI 加速器上，而不是通用 GPU；架构上将推理过程中的 prefill 与 decode 阶段拆开，让两部分可以按工作负载独立扩展。

这类推理云的目标很明确：Agent 不只是一次问答，而会产生大量 LLM 推理和工具调用，并且可能由 Agent 自己申请 API key、配置算力和发起任务。General Compute 还称，其 API 与文档同时面向人类开发者和 AI Agent 使用，客户可接入开源 LLM，也可以部署自有模型。

| 指标 | 数据 |
| --- | --- |
| 开放时间 | 2026-05-15 |
| 公司 | General Compute |
| 产品 | ASIC-first inference cloud |
| 目标负载 | 自主 AI Agent、高频 LLM 推理和工具调用 |
| 架构特点 | prefill / decode 分离，可独立扩展 |
| 模型支持 | 多个开源 LLM 家族，也支持客户自有模型 |
| 能源 | 公司称数据中心使用水电，硬件为空冷 |

### Cerebras IPO 完成：推理芯片股进入公开市场压力测试

TechCrunch 5 月 14 日报道称，Cerebras 以每股 185 美元价格发行 3000 万股，IPO 融资 55 亿美元；股票首日开盘价达到 385 美元，较发行价上涨 108%，日终对应估值约 660 亿美元。此前 5 月 11 日日报已记录其上调发行区间，这次更新标志着交易正式落地并进入公开市场检验。

Cerebras 的核心叙事从训练大芯片转向推理供应商。TechCrunch 提到，公司 2025 年收入为 5.1 亿美元，同比增长 76%，并实现 2.378 亿美元净利润；客户包括 OpenAI、G42、沙特 Mohamed bin Zayed University of Artificial Intelligence 和 Amazon Web Services。对 AI 芯片市场来说，Cerebras 首日表现会影响更多非 Nvidia 加速器公司的上市窗口。

## 全球产业动态

### 美图开拍：AI 应用商业化开始从订阅转向算力点消耗

IT之家 5 月 15 日报道称，美图公司披露 2026 年第一季度业务表现，截至 2026 年 3 月，美图影像与设计产品 AI 算力点消耗金额较 2025 年 12 月增长 59%；其中 AI 口播视频工具“开拍”增长 360%，成为生产力业务增长的重要产品之一。

这组数据反映了 AI 应用商业化的变化。过去 SaaS 产品主要看订阅用户和会员收入；生成式 AI 产品还需要看用户是否愿意为每次生成、剪辑、脚本、视频模板和营销素材付费。算力点本质上接近 Token / inference 消耗的业务化表达，它把模型调用成本和用户价值更直接地绑定起来。

### X200 RISC-V 处理器核：AI Agent 推动“系统算力”叙事升温

IT之家 5 月 15 日报道，进迭时空宣布第三代高性能 RISC-V 处理器核 X200 完成研发，面向云计算、大芯片和 AI Agent 等大算力场景，性能较上一代翻倍，预计 2027 年量产。报道将其放在“系统算力”语境中：AI Agent、个人 AI 超算、具身智能和云端智能服务需要高并发、低延迟、持续调度能力。

这条新闻虽然不是大模型发布，但反映了 AI Infra 的另一个方向。Agent 落地会让算力需求从单次模型调用扩展到长期运行、工具调用、状态同步和多任务并发，对 CPU、互联、内存和调度系统都提出更高要求。国产高性能 RISC-V 核如果进入云和大芯片场景，可能成为 AI 基础设施自主可控的一部分。
