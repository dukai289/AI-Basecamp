## 头条要闻

### GPT-5.5 从发布走向工作流落地：API 与 GitHub Copilot 同步跟进

OpenAI 4 月 23 日发布 GPT-5.5，并在 4 月 24 日更新说明称 GPT-5.5 与 GPT-5.5 Pro 已可用于 API。官方将 GPT-5.5 定位为面向真实工作的模型，重点能力集中在 agentic coding、电脑使用、知识工作和早期科研；API 计划支持 1M 上下文，标准价格为 gpt-5.5 每 100 万输入 tokens 5 美元、输出 tokens 30 美元，gpt-5.5-pro 每 100 万输入 tokens 30 美元、输出 tokens 180 美元。安全侧，OpenAI 将 GPT-5.5 的生物 / 化学与网络安全能力都按 Preparedness Framework 评为 High，并对高风险网络安全请求加入更强控制。

同一天，GitHub 宣布 GPT-5.5 在 GitHub Copilot 中开始 GA 推出，覆盖 VS Code、Visual Studio、Copilot CLI、Copilot cloud agent、github.com、GitHub Mobile、JetBrains、Xcode 和 Eclipse 等入口，面向 Copilot Pro+、Business 与 Enterprise 用户。GitHub 同时给出 7.5 倍 premium request multiplier 的促销期计费口径。对开发者而言，这意味着 GPT-5.5 不只是一个 ChatGPT 里的新模型，而是开始进入 IDE、CLI、云端 Agent 和移动端的工程工作流。

## 模型发布与更新

### UniWorld-V2.5：视觉生成开始攻克中文密集文字、信息图和 GUI 截图

量子位 4 月 25 日报道，兔展智能推出 UniWorld-V2.5，并将其放在 GPT-Image-2、Nano Banana 2 等最新图像模型的对照语境中观察。报道展示的重点不是普通文生图，而是更难的结构化视觉任务：中文高考试卷、中文简历、社交媒体界面、微博热搜、YouTube 页面、人体解剖信息图、太阳系信息图和商业海报等。核心变化在于，模型不只要画面好看，还要同时处理文字、布局、图表、图文关系和场景逻辑。

这条动态值得放进日报，是因为视觉模型竞争正在从“真实感”和“风格”转向“可读、可用、可交付”。如果一个生成模型能稳定输出中文密集文字、复杂 UI、信息图和商业排版，它就会直接进入教育出版、电商素材、营销设计、科普内容和产品原型等生产场景。兔展智能披露，UniWorld-V2.5 将超过 80% 的 token 预算用于意图理解、推理与布局规划，这也说明多模态生成的路线正在向“先理解和设计，再生成图像”倾斜。

### DeepSeek-V4：1M 上下文成为官方服务标配，旧模型名进入迁移倒计时

DeepSeek-V4 在 4 月 24 日正式上线并同步开源后，仍是近 48 小时内中文 AI 圈最集中的技术事件之一。量子位与 IT之家均报道，DeepSeek-V4 包含 DeepSeek-V4-Pro 和 DeepSeek-V4-Flash 两个版本：V4-Pro 为 1.6T 总参数、49B 激活参数；V4-Flash 为 284B 总参数、13B 激活参数；两者都支持 1M 上下文，并支持非思考、思考等推理模式。API 侧可通过 `deepseek-v4-pro` 和 `deepseek-v4-flash` 调用，旧模型名 `deepseek-chat` 与 `deepseek-reasoner` 将在 2026 年 7 月 24 日停用。

这次发布的影响还在基础设施侧继续扩散。DeepSeek 把 1M 上下文放成官方服务标配，会迫使 Agent 框架、RAG 系统、推理平台和云厂商重新评估上下文管理方式。原先很多流程依赖摘要、切片和检索绕开上下文限制；当百万上下文变得更便宜、更常见，工程重点会转向：什么时候直接放全量上下文，什么时候仍然需要外部检索和任务编排。

| 指标 | DeepSeek-V4-Pro | DeepSeek-V4-Flash |
| --- | --- | --- |
| 总参数 | 1.6T | 284B |
| 激活参数 | 49B | 13B |
| 上下文窗口 | 1M tokens | 1M tokens |
| 典型定位 | 高难推理、Agentic Coding、复杂 Agent | 更经济的日常 Agent 与高吞吐任务 |
| API 模型名 | `deepseek-v4-pro` | `deepseek-v4-flash` |

## 融资与交易

### 资本消息暂未成为本窗口主线，商业化信号转向“模型进入工作流”

近 48 小时内，可核验的重点并不集中在单笔融资，而是集中在模型和 Agent 能力进入付费产品、开发者工具与企业平台。GPT-5.5 在 API 和 GitHub Copilot 中推出，Google Cloud Next 继续强化企业 Agent 平台，飞书项目把 MCP、CLI、AI 应用和 AAMP 协议放到项目管理协作里，天翼云则继续强调 AI Token 普惠化和国产云算力底座。

## 全球产业动态

### Google Cloud Next 2026：企业 Agent 进入平台化、数据化和安全化阶段

Google 4 月 24 日发布 Cloud Next 2026 回顾，把本届大会的重点总结为 Gemini Enterprise Agent Platform、第八代 TPU、Agentic Data Cloud、AI 安全和 Workspace Intelligence。Gemini Enterprise Agent Platform 面向构建、治理和扩展 AI Agent，提供 Gemini 3.1 Pro、Gemini 3.1 Flash Image、Lyria 3，并加入 Claude Opus 4.7。Gemini Enterprise app 则提供 no-code Agent Designer、后台运行的 long-running agents 和 Agent Inbox。

基础设施侧，Google 推出面向训练的 TPU 8t 和面向推理的 TPU 8i，称 TPU 8i 可带来 80% 更好的 performance-per-dollar；同时发布 Virgo Network 与 Managed Lustre，后者可达到 10TB/s 数据移动能力。数据与安全侧，Agentic Data Cloud 通过 Knowledge Catalog、Cross-Cloud Lakehouse 等能力让 Agent 更好理解企业数据；安全产品则把 Google 威胁情报与 Wiz 结合，推出 Threat Hunting agent、Detection Engineering agent 等专用 Agent。

### 飞书项目开放平台升级：从“对人开放”走向“对 Agent 开放”

4 月 23 日，飞书项目在 2026 飞书项目生态日上发布面向 AI 时代的一组开放能力，包括 MCP 能力升级、飞书项目 CLI、AI 应用体系和 AAMP 开源协议。量子位报道，飞书项目 MCP 服务已覆盖工作项管理、视图与度量分析、团队与个人待办等 40+ 工具，并支持 OAuth 等授权方式；新发布并开源的飞书项目 CLI，目标是通过渐进式披露等机制提升模型友好度、稳定性并节省 token。

这类更新反映出企业协作软件的新竞争点：平台不仅要让人好用，也要让 Agent 安全、稳定、可授权地读写业务对象。飞书项目提出的 AAMP 协议，则试图让平台与智能体、智能体与智能体之间标准化地进行异步任务分发和确认。对于企业落地来说，这比“多接几个模型”更关键，因为真实协作场景需要权限边界、任务状态、异步确认和可追踪执行链路。

### JiuwenClaw Team Skills：多 Agent 协作开始沉淀为可复用标准能力包

4 月 24 日，量子位报道 openJiuwen 社区发布 JiuwenClaw Team Skills，称其为面向多 Agent 协作的标准化能力包规范。Team Skills 的核心，是把一次成功的多智能体协作链路沉淀下来，包括需求拆解、团队组建、任务分配、通信机制、冲突处理和交付规范。其文件结构包括 `SKILL.md`、`roles/`、`workflow.md`、`bind.md`、`dependencies.yaml`，并可扩展 examples、templates、assets 等目录。

这条线索和 Anthropic 的 Agent Skills、Codex / Claude Code / Cursor 的技能体系相互呼应。单 Agent Skill 解决“一个 Agent 怎么做事”，Team Skill 则开始处理“一个 Agent 团队怎么配合”。如果 Team Skills 这类规范能跨框架复用，Agent 工程会从临场编排走向流程资产沉淀：优秀分工、检查点、角色职责和交付格式不再只存在于一次会话里，而是可以复制到下一次任务。

### AI Token 普惠化：天翼云给出中国日均 Token 调用量参考坐标

IT之家 4 月 23 日报道，2026 智能云生态大会 · 智能云创新论坛将于 4 月 29 日在福州召开，天翼云将展示面向智能时代的 Token 能力体系。报道披露，中国日均 Token 调用量从 2024 年初约 1000 亿，增长到 2025 年底约 100 万亿，并在 2026 年 3 月突破 140 万亿，两年增长超过千倍。天翼云自有及接入智算总规模达到 91 EFLOPS，并已在息壤平台接入中国电信星辰、智谱、豆包、DeepSeek 等模型。

这个数据口径可以作为观察国内 AI 基础设施的一个坐标。模型发布、Agent 产品和企业应用最终都会落到 Token 调用量、推理成本、并发吞吐和异构算力调度上。随着 OpenClaw、DeepSeek-V4、Kimi K2.6 等事件把 Agent 使用频率继续拉高，“AI Token”会越来越像云计算时代的 CPU 小时与带宽，成为衡量基础设施供给和应用活跃度的共同语言。
